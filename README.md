🚀 Featured Project
🛡️ Hopeful Dossou — Cybersecurity Portfolio

Portfolio professionnel conçu pour Hopeful Dossou, étudiant et futur ingénieur en systèmes, réseaux et cybersécurité.

L'objectif était de créer un portfolio moderne permettant de présenter son parcours, ses compétences, ses expériences et ses projets, tout en lui donnant la possibilité de gérer facilement son contenu sans devoir modifier directement le code.

💡 Ce que j'ai réalisé
🎨 Conception et développement de l'interface avec Next.js
📱 Création d'une interface responsive et moderne
📝 Utilisation de Notion comme CMS
🔄 Récupération et affichage dynamique des données depuis Notion
⚙️ Mise en place d'une gestion de contenu permettant au client de modifier ses informations sans intervenir directement dans le code
📩 Intégration de Resend pour le formulaire de contact
🧩 Création de composants réutilisables
🎯 Adaptation de l'interface à l'identité et aux besoins du client
🛠️ Technologies

Next.js · React · Tailwind CSS · Notion API · Resend
